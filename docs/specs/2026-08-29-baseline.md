## 待办：环境安装清单（需人工执行，AI 不安装系统级软件）

```powershell
# 1. 安装 WSL2（管理员 PowerShell；执行后需重启）
wsl --install --no-distribution

# 2. 重启后安装 Ubuntu 发行版（沙箱集成测试与容器操作在其内进行）
wsl --install -d Ubuntu

# 3. 安装 Docker Desktop（winget 或官网下载）
winget install -e --id Docker.DockerDesktop
# 安装后启动 Docker Desktop → Settings → General → 勾选
# "Use the WSL 2 based engine"，并确认 Resources → WSL Integration 对 Ubuntu 启用

# 4. 验证
wsl --status
docker version
```

`.wslconfig`（`%UserProfile%\.wslconfig`，限内存 12GB）：

```ini
[wsl2]
memory=12GB
processors=8
swap=8GB
```
